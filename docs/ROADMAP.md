# MAIOS Roadmap

This roadmap lists implemented status and near-term direction for MAIOS after
`v0.1.0-alpha`.

## Current Alpha

- Core mission execution through `MAIOSCore`.
- Multi-agent runtime orchestration.
- Memory, retrieval, knowledge store, and reflection loops.
- Provider-based LLM adapter architecture.
- Local tool adapter layer.
- Autonomous controller with safety and governance integration.
- Distributed runtime and cognitive mesh abstractions.
- REST API, dashboard, examples, and tests.

## Next Priorities

- Stabilize public interfaces for core, autonomous, governance, and distributed
  packages.
- Add richer persistence backends for mission history, knowledge, audit logs,
  and vector search.
- Add production transport implementations for distributed runtime and
  cognitive mesh.
- Expand policy types for governance and approval workflows.
- Improve dashboard coverage for governance and distributed runtime status.
- Add packaging, release automation, and published artifacts.

## Longer-Term Direction

- Multi-agent teams with specialized roles and shared memory.
- Pluggable search and HTTP tools.
- Durable background workers.
- Stronger observability, tracing, and operational metrics.
- Hardened execution sandboxing for local tools.
